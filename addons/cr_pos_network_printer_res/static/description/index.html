Direct Print POS Payment/Invoice Receipt

Watch Video
  • No need of IoT box.
  • PoS receipt printer must supports ESC/POS commands.
  • Directly connects IP/Network-based ESC/POS printers with Odoo to print POS kitchen & payment/invoice receipts seamlessly.
  • This module is works with the same network. It means your Odoo-hosted server and your printer must be connected to the same network.
  • Works smoothly across POS on mobile, tablet, laptop, and other devices.
  • You can now also open the cash drawer connected to your printer.

Setup For Restaurant Receipt

  • Enable the Preparation Printers configuration.


  • Enter the printer IP address and port number inside the Point of Sale => Settings =>Order Printers enter the printer's IP address, and use an custom esc/pos printer.

  • Click on Order to print restaurant receipt using network printer.



Setup For Order Receipt

  • Enter the printer IP address and port number inside the Point of Sale => Configuration => Settings.
  • If the user wants to open the cash drawer during payment receipt printing or cash in/out operations, they can enable the highlighted checkbox below.
  • Enable the Automatic Receipt Printing configuration.

  • Click on validate to print using network printer
